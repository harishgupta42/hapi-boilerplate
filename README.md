# Hapi Tutorial

It contains boilerplate for hapi.js(v17 or higher) and basic user CRUD for understanding the flow.

## Prerequisites

1. Node.js v8.0.0 or higher

2. MongoDb v3.6 or higher

## Getting Started

To get started, follow these steps:

1. ```bash
   npm install nodemon
   ```
2. In the cloned directory, run `npm install --save`

3. ```bash
       NODE_ENV=development node server.js
    ```
   "developement" or any other env variable as per the env files available in ./config/*.json


4. If server runs, go to **localhost:8001/documentation**, here you will find list of all APIs, and can test it!
